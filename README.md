# Wireshark Packet Analysis Investigation

## Overview

This project documents a network traffic analysis investigation performed using Wireshark. The objective was to analyze packet captures, identify suspicious activity, investigate network behavior, and document findings using a structured cybersecurity investigation process.

This project demonstrates practical experience with network traffic analysis, packet inspection, threat identification, and technical reporting.

---

## Objective

The goal of this investigation was to:

- Analyze captured network traffic
- Identify unusual or potentially malicious activity
- Examine network protocols and communication patterns
- Use Wireshark filters to isolate relevant traffic
- Document findings and investigative conclusions

---

## Tools Used

- Wireshark
- TCP/IP Networking Concepts
- DNS Analysis
- Packet Capture (PCAP) Analysis
- Network Protocol Analysis

---

## Investigation Methodology

The investigation followed these steps:

1. Reviewed packet capture data
2. Applied Wireshark display filters to isolate traffic
3. Analyzed network conversations and protocols
4. Investigated indicators of suspicious activity
5. Documented findings and conclusions
